Установка

Выберите удобный способ. Готовый файл — без установки, или через pip.

# Скачайте netpulse.pyz из релизов и запустите: $ python netpulse.pyz
$ pip install git+https://github.com/foridorpo-blip/netpulse.git $ netpulse
$ git clone https://github.com/foridorpo-blip/netpulse.git $ cd netpulse $ python -m netpulse

Возможности

Шесть команд — полная картина вашей сети и VPN.

Команда Что делает
netpulse ip Публичный IP, страна, город, провайдер — проверка, работает ли VPN
netpulse ping TCP-пинг без прав администратора: задержка, jitter, потери
netpulse dns A и AAAA-записи домена
netpulse tls Версия TLS, издатель и срок действия SSL-сертификата
netpulse sites Проверка блокировок: DNS, IP, DPI/SNI-фильтрация, подмена сертификата
--json Вывод в JSON для скриптов, мониторинга и Telegram-ботов

Почему NetPulse

Просто, быстро, без зависимостей.

Без зависимостей

Только стандартная библиотека Python 3.9+. Один файл netpulse.pyz — готов к запуску.

TCP-пинг

Пинг по TCP без прав администратора: задержка, jitter и потери пакетов.

Проверка VPN

Показывает страну и провайдера IP и предупредит, если часовой пояс системы не совпадает с поясом IP.

Проверка блокировок

Покажет, где обрывается соединение: DNS, TCP, TLS или DPI/SNI-фильтрация.

TLS-сертификаты

Версия TLS, издатель и срок действия SSL-сертификата — на каком сайте истекает.

JSON-вывод

Флаг --json для скриптов, мониторинга и Telegram-ботов.

Частые вопросы

Короткие ответы на основные вопросы.

Как проверить, работает ли VPN?
Запустите netpulse ip — утилита покажет страну и провайдера вашего IP и предупредит, если часовой пояс системы не совпадает с поясом IP.
Как понять, почему не открывается сайт?
netpulse sites example.com покажет, где обрывается соединение: на DNS, TCP или TLS. Также обнаруживает DPI/SNI-фильтрацию и подмену сертификата.
Нужны ли зависимости?
Нет, только Python 3.9+. Есть готовый файл netpulse.pyz в релизах — скачиваете и запускаете.
На каких платформах работает?
Windows, Linux и macOS. Без прав администратора — TCP-пинг вместо ICMP.

Готовы проверить сеть?

Скачайте NetPulse и запустите первую команду за 10 секунд.
