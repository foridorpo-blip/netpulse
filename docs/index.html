NetPulse — проверка VPN, сети и блокировок сайтов

Бесплатная утилита с открытым кодом. Одна команда показывает ваш публичный IP и страну, задержку до серверов, DNS, срок TLS-сертификата и какие сайты заблокированы — и на каком этапе.

Скачать GitHub 
pip install git+https://github.com/foridorpo-blip/netpulse.git
netpulse

Возможности

netpulse ipПубличный IP, страна, город, провайдер — проверка, работает ли VPN
netpulse pingTCP-пинг без прав администратора: задержка, jitter, потери
netpulse dnsA и AAAA-записи домена
netpulse tlsВерсия TLS, издатель и срок действия SSL-сертификата
netpulse sitesПроверка блокировок: DNS, IP, DPI/SNI-фильтрация, подмена сертификата
--jsonВывод в JSON для скриптов, мониторинга и Telegram-ботов

Частые вопросы

Как проверить, работает ли VPN? Запустите netpulse ip — утилита покажет страну и провайдера вашего IP и предупредит, если часовой пояс системы не совпадает с поясом IP.

Как понять, почему не открывается сайт? netpulse sites example.com покажет, где обрывается соединение: на DNS, TCP или TLS.

Нужны ли зависимости? Нет, только Python 3.9+. Есть готовый файл netpulse.pyz в релизах.
